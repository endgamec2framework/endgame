What's included

Capabilities not in the free release

Campaign
Spear Phishing Engine
Full campaign manager: AI HTML template generator (Claude / Ollama / OpenAI), CSV recipient import, SMTP dispatch, transparent pixel open tracking, redirect-based click tracking with timestamps and IPs. Campaign detail modal with rendered preview, raw HTML tab, and full event log.
Governance
Campaign Governance
Allowlist filtering by domain or email address. Dry-run mode previews dispatch without sending. Per-campaign volume caps. Configurable expiry date. Operator kill switch that halts redirects in real time. Full audit trail of every governance action.
Reporting
Purple Team Report
One-click self-contained HTML report: MITRE ATT&CK technique heatmap, phishing funnel (sent → opened → clicked), IOC inventory by type, engagement timeline, and tailored detection recommendations for the blue team. No external dependencies — send the file.
Detection engineering
Detection Rules Export
Generate ready-to-deploy detection rules from live IOCs in three formats: Sigma YAML, Microsoft Sentinel KQL, and Splunk SPL. One endpoint — GET /api/report/detections?format=sigma|kql|spl — covers IPs, domains, file hashes, process names, registry keys, and LOLBins.
Blue team
Debrief Portal
Generate a time-limited read-only link for analysts. The portal shows the IOC inventory and campaign stats without exposing operator credentials or the full C2 interface. Configurable expiry from 1 to 168 hours. Token is a 128-bit random — not guessable.
Alerting
High-Impact Webhooks
Fire HTTP webhooks the moment a critical action lands: GETSYSTEM, DCSync, LSASS dump, credential harvest. Wire Slack, Microsoft Teams, or any HTTP endpoint. Payload includes agent ID, hostname, user, technique, and timestamp. Operators know before they check the console.
Governance
Rules of Engagement Engine
Define in-scope IP ranges and domains — the server auto-blocks any out-of-scope target before a task executes. Set engagement start/end dates, operational hours (day-of-week + time window), a prohibited-command list, and a per-host agent cap. ROE violations are logged and surfaced in real time.
Spear Phishing
Credential Capture Page
Clone any login form and inject a credential interceptor. Submitted usernames and passwords are captured, stored per-campaign, and surfaced as a live SSE event in the operator console the moment they arrive. Honeypot field included to detect automated scanners. Victim is redirected after capture.
Spear Phishing
Email Security Analyzer
Pre-campaign DNS check on the target domain: SPF record policy (pass / softfail / hardfail), DMARC enforcement level and aggregate-reporting URIs, DKIM selector probe across eight common selectors, and MX records. Generates a 0–100 risk score and a plain-English summary of phishing likelihood.
Reporting
PDF Report
Download a portable PDF of the Purple Team Report — cover page, executive summary, engagement timeline, IOC table, detection gaps, and remediation recommendations. Generated server-side in pure Go. No external executables, no headless browser, no LaTeX. One endpoint, one file to hand to the client.
Reporting
AI Engagement Narrative
One click generates a prose engagement story from the task log: an executive summary for the C-suite, a step-by-step technical narrative for the security team, a key-findings list, and tailored remediations. Powered by Claude Haiku. Works offline if ANTHROPIC_API_KEY is not set — returns a structured placeholder instead.
Reporting
Remediation Scorecard
Track which Purple Team Report recommendations the blue team has closed. Create findings (category, severity, description), update status (open → in progress → resolved → accepted risk), and record who resolved each item. Dashboard shows overall remediation percentage by category. Auto-imports findings from the report with one click.
Infrastructure
Redirector Management
Configure and monitor HTTP/HTTPS redirectors from the GUI. Register redirectors with their public IP and domain, view active-agent counts per redirector, toggle redirectors in and out of service without killing sessions, and tail their real-time traffic log. Keeps your team's C2 infrastructure visible in one place.
Infrastructure
Multi-Engagement Isolation
Partition agents, loot, phishing campaigns, and IOCs by client or engagement. Each engagement has its own namespace — switching context changes every view in the GUI. Prevents cross-contamination between simultaneous operations and makes per-client reporting trivial. Engagement-level export includes all artefacts.
Spear Phishing
Multi-Channel Pretexting
Extend phishing campaigns beyond email. Send pretexting messages via Microsoft Teams webhooks or SMS (Twilio) in addition to SMTP — same campaign governance, allowlists, dry-run mode, and kill switch apply across all channels. Unified click and open tracking in the campaign dashboard regardless of delivery channel.
Integration
Metasploit Console
Full Metasploit terminal inside the Professional GUI — live PTY session with bidirectional context sync. ENDGAME automatically pushes agent IPs and captured credentials to the MSF workspace. Active MSF sessions surface in the operator dashboard. Configurable msfrpcd RPC endpoint for deeper automation.
