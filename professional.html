What's included

Six capabilities not in the free release

Campaign
Spear Phishing Engine
Full campaign manager: AI HTML template generator (Claude / Ollama / OpenAI), CSV recipient import, SMTP dispatch, transparent pixel open tracking, redirect-based click tracking with timestamps and IPs. Campaign detail modal with rendered preview, raw HTML tab, and full event log.
Governance
Campaign Governance
Allowlist filtering by domain or email address. Dry-run mode previews dispatch without sending. Per-campaign volume caps. Configurable expiry date. Operator kill switch that halts redirects in real time. Full audit trail of every governance action.
Reporting
Purple Team Report
One-click self-contained HTML report: MITRE ATT&CK technique heatmap, phishing funnel (sent → opened → clicked), IOC inventory by type, engagement timeline, and tailored detection recommendations for the blue team. No external dependencies — send the file.
Detection engineering
Detection Rules Export
Generate ready-to-deploy detection rules from live IOCs in three formats: Sigma YAML, Microsoft Sentinel KQL, and Splunk SPL. One endpoint — GET /api/report/detections?format=sigma|kql|spl — covers IPs, domains, file hashes, process names, registry keys, and LOLBins.
Blue team
Debrief Portal
Generate a time-limited read-only link for analysts. The portal shows the IOC inventory and campaign stats without exposing operator credentials or the full C2 interface. Configurable expiry from 1 to 168 hours. Token is a 128-bit random — not guessable.
Alerting
High-Impact Webhooks
Fire HTTP webhooks the moment a critical action lands: GETSYSTEM, DCSync, LSASS dump, credential harvest. Wire Slack, Microsoft Teams, or any HTTP endpoint. Payload includes agent ID, hostname, user, technique, and timestamp. Operators know before they check the console.
